### What I build

I'm a Computer Engineering student (The IIE) who prefers shipping working full-stack systems over toy exercises — decoupled APIs with real auth, background services, and CI, not just CRUD screens. Recent work spans:

- **ASP.NET Core Web API + Blazor Server** — JWT auth, SignalR real-time updates, Factory/Observer patterns, Docker Compose orchestration, GitHub Actions CI
- **ASP.NET Core MVC** — role-based approval workflows (ASP.NET Identity), EF Core, AES-encrypted document handling, CSV report generation
- **Android / Kotlin (Jetpack Compose)** — Firebase Firestore real-time sync, Gemini Vision OCR for receipt scanning, Firebase Cloud Functions
- **Serverless** — Azure Functions + Azurite for local blob/queue/table emulation
